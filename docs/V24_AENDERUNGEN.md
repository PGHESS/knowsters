# Knowsters v24 – Mobile UX Blueprint / Phase 1

Stand: 26.09.2026

## Ziel
Knowsters wird ab jetzt nicht mehr screenweise wie ein Browser-Prototyp weitergeschoben, sondern anhand eines verbindlichen Mobile-Game-Blueprints aufgebaut.

V24 setzt den ersten Teil davon direkt um.

- Verbindlicher Mobile UX Blueprint

- Skills und Stil künftig unter Team / Profil statt als Haupttabs
- Safe-Area-/Fullscreen-Shell bleibt bestehen
