# Knowsters v25 – Phaser Rendering Spike

Stand: 26.09.2026

V25 ist kein kompletter Engine-Wechsel, sondern ein testbarer Rendering-Spike.

## Testziel
- echtes Fullscreen-Mobile-Game-Gefühl
- Mensch als sichtbarer Beschwörer
- Begleitwesen in der Welt
- Portrait-Taktikmodus mit minimalem HUD
- Bewegungsreichweite direkt im Feld
- Informationen nur auf Abruf
- Idle-, Move- und Trefferbewegungen

## Technik
- Phaser 4.2.1
- logische Mobile-Auflösung 390 × 844
- Phaser Scale FIT
- Touch-first
- WebGL/Canvas über Phaser AUTO
- aktuelle Knowsters-Assets
