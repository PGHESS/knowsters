# Knowsters

Knowsters ist ein Adventure- und Taktik-RPG-Prototyp mit menschlichem Spielercharakter, Begleitwesen, taktischen Kämpfen und einem Wissens-/Entwicklungssystem.

## Aktueller Teststand
- Zielstand: **v22**
- Prolog: **Die letzte Brücke**
- 4 Wächter: Lumi, Pyro, Terra, Nivaro
- taktisches Raster, Fähigkeiten, Gegnerphasen und Kampf-FX
- Avatar-Editor und Begleitwesen-Grundlage
- Wissensprofil mit 10 Wissensgebieten
- individuelle Wesenattribute und Entwicklung

## Web-Test / GitHub Pages
Dieses Repository ist für einen einfachen Safari-/Mobile-Test vorbereitet.

Die veröffentlichbare Spielversion wird als **Knowsters-v22-WebDeploy.zip** im Repository abgelegt.  
Ein GitHub-Actions-Workflow entpackt die Datei automatisch und veröffentlicht den enthaltenen Web-Build über GitHub Pages.

### Erwartete ZIP-Struktur
```
Knowsters-v22-WebDeploy.zip
└── Knowsters-v22-WebDeploy/
    ├── index.html
    ├── *.js
    ├── *.css
    ├── assets/
    ├── icons/
    └── manifest.webmanifest
```

## Entwicklung
Der eigentliche Entwicklungsstand wird versioniert weitergeführt. Änderungen werden nicht direkt an produktiver Spiellogik „blind“ durchgeführt; funktionierende Stände sollen nachvollziehbar bleiben.
